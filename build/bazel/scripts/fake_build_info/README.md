# Fake Build Info (`@fuchsia_build_info`)

This directory contains static, mock Starlark definitions used to mock the
`@fuchsia_build_info` repository during pre-flight RBE/ResultStore
authentication tests (`fx rbe auth`).

The diagnostic test workspace generated by `minimal_workspace.py` maps the
`@fuchsia_build_info` Bazel module to this static directory instead of
dynamically generating build info arguments from GN.
