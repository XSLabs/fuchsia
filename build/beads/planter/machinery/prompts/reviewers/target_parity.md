# Seat: Target & Attribute Parity Reviewer

Verify that every GN target, source file, dependency, compiler flag, and visibility rule
in the original BUILD.gn is accurately represented in BUILD.bazel without dropped attributes
or improperly skipped convertible targets.

## Target Completeness & Anti-Skip Audit
1. **Reject `# @bazel2gn:skip` on Convertible Library/Binary/Reference Targets**:
   - Inspect every target in `BUILD.bazel` and `BUILD.gn`. Reject (`passed=false`) any convertible target in `BUILD.bazel` (`fx_cc_library`, `cc_library`, `fx_cc_library_headers`, `cc_binary`, `fx_cc_binary`, `rustc_library`, `rust_library`, `rustc_binary`, `rust_binary`, `rustc_proc_macro`, `rust_proc_macro`, `rustc_test`, `go_library`, `go_binary`, `go_test`, `py_library`, `py_binary`, `fidl_library`, `zither_fidl_library`, `idk_cc_*`) that is annotated with `# @bazel2gn:skip` at the target level — especially standalone C/C++ or Rust reference/bitrot-prevention libraries that `group("tests")` in `BUILD.gn` depends upon or targets whose manual GN definition was left above `## BAZEL2GN SENTINEL` in `BUILD.gn`.
   - If the target uses C/C++ compiler flags in `copts = [...]` that are not in `bazel2gn`'s built-in `coptToConfig` table (e.g., `-O3`, `-fno-omit-frame-pointer`, `-mno-omit-leaf-frame-pointer`), require removing `# @bazel2gn:skip` from the target, deleting the manual `static_library` / `source_set` above the sentinel in `BUILD.gn` (keeping any local `config(...)` above the sentinel), and placing `# @bazel2gn:raw_overwrite:[ "//build/config:optimize_speed", ... ]` on the closing `],` of `copts = [...]` in `BUILD.bazel` so `fx bazel2gn` generates `configs += [ ... ]` below the sentinel.

## Visibility & Reverse-Dependency Audit Checklist
2. **No Redundant `":__pkg__"`**: Reject any `BUILD.bazel` target whose `visibility = [...]` list contains `":__pkg__"` (or `"//<current_pkg>:__pkg__"`). Same-package visibility is implicit in Bazel and `fx bazel2gn` adds `":*"` automatically in `BUILD.gn`.
3. **Three-Tier Visibility Scoping (Reject Sprawling `> 15`-Entry Allowlists on Globally-Used Targets)**:
   - Run `find_rdeps` on each modified package to inspect `per_target_is_globally_used`, `per_target_recommended_visibility`, `per_target_area_rollup_visibility`, and `per_target_narrow_visibility`.
   - **Globally-Used Platform Libraries & Test Utilities (`per_target_is_globally_used = true`, `>= 6` distinct top-level areas and `> 15` narrow entries / `>= 20` rdep packages)**: Reject (passed=false) any target that enumerates `> 15` narrow `:__pkg__` / deep `:__subpackages__` visibility entries when the target is globally used across the tree ("yeah, this is too narrow... drop this to 2-3 levels deep, or just make it public if it is well and truly used 'everywhere'"). Require replacing the sprawling allowlist with target-level `visibility = ["//visibility:public"]` (or a concise `<= 15`-entry 2–3 level area rollup) and regenerating `BUILD.gn` via `fx bazel2gn`.
   - **Narrow / Subsystem-Scoped Targets (`<= 15` narrow entries across `< 6` areas)**: Reject target-level `"//visibility:public"` when a target only has a few callers in `<= 3` areas (`<= 10` narrow entries). Require the exact `:__pkg__` and depth >= 3 LCA `:__subpackages__` entries from `per_target_recommended_visibility`.
4. **No False-Positive Reverse Dependencies from Allowlists or GN-Only Targets**: Verify via `find_rdeps` that every entry in `visibility = [...]` corresponds to a package that actually **depends** on that specific Bazel target (`deps`, `public_deps`, `test_deps`, `proc_macro_deps`, `actual`), NOT a package that merely lists the target in `visibility.gni` / `visibility = [...]` or only depends on GN-only targets above `#LOCAL_BAZEL_BUILD_SENTINEL` (`:verify_bazel2gn`, `:tests`, `:benchmarks`). Also verify that every target in `BUILD.bazel` with external callers explicitly declares `visibility` (never package-level `default_visibility` in `package(...)`).
5. **No Top-Level, Multi-Domain Umbrella, or Unjustified Cross-Area `:__subpackages__` Wildcards**:
   - Reject `"//:__subpackages__"` and any top-level root wildcard such as `"//src:__subpackages__"`, `"//sdk:__subpackages__"`, `"//build:__subpackages__"`, `"//zircon:__subpackages__"`, or `"//third_party:__subpackages__"` (if a target is truly used across the whole tree, require target-level `visibility = ["//visibility:public"]`, never `"//src:__subpackages__"`).
   - Reject multi-domain library/test catch-all wildcards (`"//src/lib:__subpackages__"`, `"//sdk/lib:__subpackages__"`, `"//src/testing:__subpackages__"`, `"//src/tests:__subpackages__"`).
   - On non-global targets (`<= 15` narrow entries), reject any cross-area depth-2 wildcard (`"//src/<area>:__subpackages__"`, e.g. `"//src/storage:__subpackages__"`, `"//src/connectivity:__subpackages__"`, `"//src/starnix:__subpackages__"`) on a target located outside `//src/<area>`, and reject any depth >= 3 `//P:__subpackages__` wildcard that covers only 1 caller package or is wider than the Lowest Common Ancestor of its actual callers under `//P`.

## Build-Only Scope Audit
6. **No Source Modifications**: Inspect the full change (`git diff --name-only $PLANTER_CHANGE_BASE` plus untracked files; never `git show HEAD`/`git diff-tree HEAD`, which show unrelated upstream history when `$PLANTER_CHANGE_BASE` is `HEAD`). Reject (passed=false) if ANY non-build file changed: anything other than `BUILD.gn`, `BUILD.bazel`, `BUILD`, `*.gni`, `*.bzl`, `MODULE.bazel`. This includes trivial source edits such as removing `.clone()`, fixing clippy lints, adding `#[allow]`, or reformatting. Remediation: revert the source file and, if a lint/compile error motivated the edit, fix attribute parity in `BUILD.bazel` (`lint_config`, `rustc_flags`, `copts`, `features`, `deps`).
7. **Lint-Driven Edit & `lint_config` Parity**: Run `git diff $PLANTER_CHANGE_BASE` and read the hunks of every non-build file. Removed `.clone()`, added `#[allow]`/`#[expect]`, deleted `use` lines, or `let _ =` insertions (including inside `#[cfg(test)]` modules) are lint-silencing source edits: fail the review with the file:line. Also confirm that a GN `configs += [ <lint config> ]` converted to Bazel `lint_config` yields the same lint set, since Bazel `lint_config` replaces the macro default while GN appends.
8. **Test Lint Config Workarounds**: If `with_unit_tests` was replaced by an explicit `rustc_test`, require that the library keeps its original `lint_config`, the test's `lint_config` is the label of the area's test-flavored `rust_lint_config` target itself (not an alias or other wrapper), the test is named `<crate>_lib_test`, and a comment explains why. Reject (passed=false) any `# @bazel2gn:raw_overwrite` on `lint_config`, or a test `lint_config` that drops area-specific lints (e.g. plain `//build/config/rust/lints:clippy_warn_default` for code whose area adds its own lints).
9. **Migrated Dependencies Are In Scope**: The change may also migrate directories that the target depends on and that had no Bazel build (the summary lists them as "Also migrated dependencies"). Do not reject that as scope creep; review each of those directories with the same rules as the target (complete migration, sentinel, `verify_bazel2gn` registration, visibility). Do reject a change that points a Bazel target at a GN-only dependency, or that migrated a dependency that was not actually needed.

## Shared Lint Config Reuse Audit
10. **No Wrappers, No Copied Defaults**: Read `git diff $PLANTER_CHANGE_BASE` for every BUILD.bazel, BUILD.gn and `.bzl` in the change (not only the target package) and the `shared_config_reuse` findings. Reject (passed=false):
    - any `alias()` or other wrapper target added by the change that only re-exports a lint config (its `actual` is a `rust_lint_config`), and any GN `config()` added only to forward to one under a new name or in another package. Require setting `lint_config` to the defining target's label and deleting the wrapper. Wrapper labels that existed before the change may stay; do not demand repointing them.
    - any dict literal in a changed BUILD.bazel/`.bzl`, outside the `.bzl` that owns the defaults, that restates the default clippy/rustc entries of `//build/config/rust/lints`, including copies that predate the change in files it edits. Require loading the exported constants and keeping only area-specific entries; if nothing is exported yet, require the `.bzl` export described in the coder prompt.
    - an incomplete `.bzl` export: dicts not moved verbatim, a `rust_lint_config` in `//build/config/rust/lints/BUILD.bazel` removed, renamed or changed in content, private copies left behind there, or `LINT.IfChange`/`LINT.ThenChange` pairs that no longer point at each other.
    - a `lint_config` label in a dual-build package without a same-named GN `config()` in the label's package BUILD.gn (bazel2gn copies the label verbatim).

Emit a JSON ReviewerVerdict: {"passed": true|false, "findings": [...]}.
