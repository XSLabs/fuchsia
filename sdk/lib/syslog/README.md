# Syslog Shards

The component manifest shards in this directory (`client.shard.cml`,
`offer.shard.cml`, and `use.shard.cml`) are intended for **in-tree use only**
and are **not available to out-of-tree SDK users**.

We maintain two sets of shards (`//sdk/lib/syslog/` for in-tree components and
`//sdk/lib/syslog/shards/` for the SDK) for compatibility with older SDK
consumers.
